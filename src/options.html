Scheduled Sends

Queue files (and an optional prompt) to a new chat — optionally in a Project — to send at a set time or when your 5-hour usage next resets. Files are stored in the extension until they go out.

No scheduled sends queued.

Heads-up: a job can only fire while your browser is running and you're logged into claude.ai — at fire time the extension opens a background claude.ai tab, attaches the files, types the prompt, and clicks Send. If Claude is down, the job waits and sends itself once the outage clears (up to 6 hours, then it goes anyway); Run now overrides the wait.

Workflows

A workflow runs one piece of work through several chats that hand it back and forth — chat A drafts, chat B criticises, A revises, and so on — so each pass improves on the last. Each workflow is a template: name it for the matter, add that matter's documents, and starting a run hands both to the run and puts the template back to its resting name, empty and ready for the next one.

No workflows yet. New workflow starts one from scratch.

Runs

No runs yet. Start one from a workflow above — it opens its own Chrome window, walks the steps, and waits for each reply before sending the next.

A run drives the real UI, so it needs your browser open and logged into claude.ai, and it leaves each chat's conversation open so you can read it. Claude's reply travels between chats the way you would move it: the copy box under the finished answer, which copies the answer without the thinking. If Claude is down, the run waits mid-workflow and picks up where it left off.
