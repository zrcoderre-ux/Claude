The floating meter appears on claude.ai. It reads your usage automatically and keeps it fresh in the background.

On by default. Shows a warning pill above the meter (and a desktop notification) while status.claude.com reports Claude degraded, down, or under maintenance.

On by default. A scheduled send waits instead of firing into an outage, then goes out on its own once Claude recovers. Degraded performance only warns — it doesn't hold. After 6 hours of waiting a job sends anyway rather than never leaving, and Run now always overrides the wait.

Off by default. When on, adds your pay-as-you-go spend (e.g. $0.00 / $30.00) to the meter's detail panel.

Off by default. Claude reports whole-number percentages; when on, the session meter adds an estimated tenths place (e.g. 48.3%) by tracking token use between each 1% step.

Off by default. Clicks Claude's Continue button when a long turn hits the tool-use / length limit — and clicks Try again once your usage resets after hitting a limit. Works on claude.ai and Claude Code, even in background tabs. Stops after continues (per page load); toggle off/on to resume after that.

Off by default. Clicks Claude's Allow once button as soon as a permission prompt appears, so an agentic run doesn't stall waiting for you. It only ever clicks Allow once — never Allow always or Allow for this chat — so nothing is granted beyond the single call in front of it. You are approving those calls sight-unseen; leave this off if you want to read each prompt. Stops after 100 clicks per page load; toggle off/on to resume.

Off by default. When a reply hands you a file, its Download button is clicked for you once the answer has finished — so a produced document lands in your Downloads folder without you fetching it. New files only: it saves out of a reply that arrived while the tab was open, never out of a chat's backlog, so opening an old conversation saves nothing. Only files a reply offers directly; an artifact you'd download from its own panel isn't one. It stops after files per page load.

Advanced: paste the exact request URL the Usage page loads (from your browser's Network tab) to pin it. Leave blank to auto-detect.
